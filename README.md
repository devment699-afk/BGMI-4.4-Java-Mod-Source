# BGMI 4.4 Aesthetic Mod Menu Source (Java)

This is a professional Android Java source code template for a BGMI mod menu. It features a high-quality floating UI with toggles for various features.

## Features Included (UI Toggles)
- **Visuals**: ESP, Hide ESP (Recording), Sketch Line.
- **Combat**: Aimbot, Bullet Track, Magic Bullet.
- **Skins**: X-Suits, Gun Skins, Car Skins, Loot Box, Kill Message.
- **Security**: Full Internal Antiban Scaffold.

## How to Use
1.  Open the project in **Android Studio**.
2.  Implement your game-hacking logic (offsets, memory reading/writing) in the `FloatingWidgetService.java` listeners.
3.  Build and sign the APK.
4.  Grant the "Draw over other apps" permission when prompted.

## Project Structure
- `MainActivity.java`: Handles permissions and starts the service.
- `FloatingWidgetService.java`: Manages the floating menu UI and feature logic.
- `floating_menu.xml`: The aesthetic layout for the mod menu.
